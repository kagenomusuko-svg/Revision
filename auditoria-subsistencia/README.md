# Auditoría de subsistencia epistemológica

Este directorio conserva entregas documentales de la auditoría sustantiva del corpus epistemológico. Las respuestas y productos posteriores de esta auditoría se incorporarán aquí, en versiones sucesivas, preservando el historial.

## Entrega v2.0

La versión 2.0 contiene el informe maestro, matrices de aportaciones e instrumentos, registro de comprobaciones matemáticas con script reproducible y registro de cobertura. La auditoría es sustantiva pero parcial; los límites documentales se detallan en los propios artefactos.
